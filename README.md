# Titanic Survival Prediction using Machine Learning

## Project

This project predicts whether a passenger survived the Titanic disaster using Machine Learning. It was developed as part of a Data Science Internship (Week 2) to learn data preprocessing, model training, and model evaluation.

## Dataset

- Titanic Dataset
- Total Records: 891
- Target: Survived

## Features Used

- Pclass
- Sex
- Age
- Fare

## Tools and Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Jupyter Notebook

## Machine Learning Models

- Logistic Regression
- Decision Tree Classifier

## Workflow

1. Import libraries
2. Load the dataset
3. Data preprocessing
4. Handle missing values
5. Convert categorical data
6. Train-test split
7. Train Logistic Regression model
8. Train Decision Tree model
9. Compare model performance
10. Final evaluation

## Results

| Model | Accuracy |
|--------|----------|
| Logistic Regression | 80.45% |
| Decision Tree | 73.18% |

Logistic Regression achieved better accuracy than the Decision Tree model.

## What I Learned

- Data preprocessing using Pandas
- Train-test split
- Building classification models
- Comparing machine learning algorithms
- Model evaluation using accuracy and classification report
